# Cyber Network Info Tool

## About

Cyber Network Info Tool is a beginner-friendly Python project that displays basic network information from the local computer.

## Features

- Displays the computer hostname
- Displays the local IP address
- Displays the default gateway
- Displays the DNS server

## Technologies Used

- Python
- Python Socket Module
- Python Subprocess Module
- Windows Networking Commands

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python network_info.py
```
